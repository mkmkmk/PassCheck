# PassCheck
Checks if your password has been stolen in known data breaches on **[haveibeenpwned.com](https://haveibeenpwned.com)**. It uses the secure k-Anonymity method – your password never leaves this device; only the first 5 characters of the password's HASH (SHA-1) are sent to the checking service.<br>

**[Try here](https://mkmkmk.github.io/PassCheck/)**
